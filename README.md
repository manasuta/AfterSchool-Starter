# Swiftでアプリ画面を作ろう

[参加者用の教材をダウンロード（ZIP）](https://github.com/manasuta/AfterSchool-Starter/raw/refs/heads/main/AfterSchool-Starter.zip)

1. MacのFinderでZIPを展開し、フォルダ内の「ここから.html」をブラウザで開きます。
2. 同じフォルダの「AfterSchool.xcodeproj」をXcodeで開き、iPhoneシミュレーターを選んで ⌘R。灰色の枠がある「放課後」の画面が出れば準備完了です。
3. ガイドの完成見本を見て、投稿者欄・写真と一言・いいねボタンから好きな部品をひとつ選びます。設計図を読みながら部品を作り、タイムラインに載せてみましょう。
